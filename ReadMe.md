## Getting Started

- Be sure to install all of the dependencies by running "pip install -r requirements", then setting the environment variable "$FLAG_SEED" by running "$env:FLAG_SEED = '--your unique value here--'", if you don't want
  to use the default seed. Then simply run app.py.

### Dependencies

- All of the dependencies are listed inside of 'requirements.txt'

### Installing

- Run 'git clone https://github.com/BrennanA757/https://github.com/BrennanA757/PWP---Mini-Project-4.git' and 'cd https://github.com/BrennanA757/PWP---Mini-Project-4'

### Executing program

- Simply type "python app.py" with the environment variable set.
